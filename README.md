# Kattis Solutions
This repository contains my solutions to programming problems from [Kattis](https://open.kattis.com/).
\
The solutions were created as part of my practice in algorithms, problem solving, and competitive programming.

## Repository Structure
Each problem is stored in its own directory named after the problem title displayed on Kattis.
\
Source files generally use the corresponding Kattis problem ID as their filename.
\
Some problem directories may contain solutions written in more than one programming language.

## Languages
The repository currently contains solutions written primarily in:
- C
- Java

Additional languages may be added in the future.

## Purpose
This repository serves as a record of my progress in:
- Algorithmic problem solving
- Competitive programming
- Data structures and algorithms
- Writing efficient and concise programs
- Practicing different programming concepts and languages

## Notes
- Each directory corresponds to a problem from Kattis.
- Problem statements are not reproduced in this repository.
- Source files generally retain the Kattis problem ID as their filename.
- Some problems may contain multiple implementations in different programming languages.
- Solutions may not always represent the most optimal possible approach, as this repository also documents my learning progress.
